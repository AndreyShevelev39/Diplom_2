# Stellar Burgers API Tests

Автоматизация тестирования API для космической бургерной.

## Стек технологий:
- **Java 11**, **JUnit 4**
- **REST Assured** - работа с HTTP запросами.
- **Allure** - генерация отчетов.
- **Maven** - сборка проекта.

## Основные проверки:
1. **Пользователь**: Создание (успех, дубль, неполные данные), Логин (успех, ошибка).
2. **Заказы**: Создание (с авторизацией, без, с ингредиентами, ошибки состава).

## Запуск:
```bash
mvn clean test
mvn allure:serve
